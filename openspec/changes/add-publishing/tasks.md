## 实现说明（2026-10-11）

29 项任务已在代码层完成。新增测试 `scripts/publish.mjs`，
并在 `scripts/ui-entry.mjs` 中增补发布页断言。八套测试全绿。

### 关键修复的实际影响面（比预想更大）

`toCliArgs` 的布尔序列化修复**不止影响发布**：`--headed`（窗口登录）、`--no-proxy`、
`--official-api`、`--allow-unsafe` 全都受同一个 bug 影响。也就是说上一轮刚加的
「窗口登录」按钮此前同样传不进 `--headed`，只是因为扫码登录默认走 qr 才没有暴露。

### 用真实命令行做的验证

测试不只断言参数对象，还用假解释器把**实际收到的命令行**回显出来核对：

| 场景 | 断言 |
| --- | --- |
| 预检（未确认） | 命令行里**没有** `--exec` |
| 确认后 | 命令行里**有** `--exec`，且**后面不跟 `true`**（旧实现会跟，argparse 直接报错） |
| 公众号确认后 | 命令行里同样有 `--exec` |
